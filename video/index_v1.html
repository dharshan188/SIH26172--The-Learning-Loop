02 · Our Solution

MARVIN listens
on the edge

A two-stage TinyML wake-word detector that runs entirely on an ESP32. The cloud is used only after it hears “MARVIN”.

  • On-device wake-word detection
  • Low-power I²S microphone
  • Cloud speech-to-text on demand
ESP32-WROOM-32
INMP441 mic
TinyML on-chip
03 · How it works

From sound to command

01CaptureINMP441 microphone streams 16 kHz audio
02ExtractLog-Mel features computed on the ESP32
03DetectStage 1 flags possible “MARVIN” candidates
04VerifyStage 2 confirms the wake word and rejects false alarms
05TranscribeOnly now is audio sent to the cloud for speech-to-text
04 · Built for the edge
